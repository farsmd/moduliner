# مودولاینر (Moduliner)

مینی‌فریم‌ورک PHP ماژولار بر پایه الگوی **HMVC** — سبک، بدون وابستگی، مخصوص هاست‌های اشتراکی با دیتابیس SQLite.

## ویژگی‌ها

- **بدون وابستگی:** PHP خالص، بدون Composer
- **ماژولار (Plug & Play):** هر ماژول روت، کنترلر، مدل و ویوی خودش را دارد
- **مسیریابی پویا:** اسکن خودکار `routes.php` ماژول‌ها
- **بارگذاری خودکار:** namespaceها در لحظه نیاز لود می‌شن

## نصب

تنها راه نصب، نصب‌کننده تک‌فایل است (جزئی از سیستم نیست):

1. فقط فایل `install.php` را در هاست خالی آپلود کنید
2. در مرورگر باز کنید: `https://yoursite.com/install.php`
3. مراحل را دنبال کنید — خودش آخرین نسخه را از گیت‌هاب دانلود و نصب می‌کند
4. بعد از نصب موفق، فایل نصب‌کننده به‌صورت خودکار حذف می‌شود

## ساختار

```
├── .htaccess          هدایت به index.php
├── index.php          نقطه ورود
├── core/              هسته (App، Router، Controller، Model، Database)
├── database/          فایل SQLite (در گیت نیست)
└── modules/           ماژول‌ها
    └── user/          مدیریت کاربران (لاگین/سشن/نقش)
        ├── Controller.php
        ├── routes.php
        ├── Models/UserModel.php
        └── views/
```

## ساخت ماژول جدید

1. پوشه `modules/blog/` بسازید
2. فایل `routes.php` را اضافه کنید:
```php
$router->get('blog', 'blog', 'Controller', 'index');
```
3. کلاس `Modules\blog\Controller` را در `Controller.php` بسازید
4. تمام — روت به‌صورت خودکار شناسایی می‌شود

## نسخه‌ها

- **۰٫۰٫۱** — هسته + ماژول کاربر (لاگین، سشن امن، نقش‌های قابل‌توسعه)
- **۰٫۰٫۲** — نصاب خودکار + ماژول آپدیت از گیت‌هاب
- **۰٫۰٫۳** — نصب‌کننده تک‌فایل (دانلود خودکار از گیت‌هاب)
- **۰٫۰٫۴** — حذف install.php؛ تنها مسیر نصب، نصب‌کننده تک‌فایل است (حذف خودکار بعد از نصب)
